# Codee v1.1.0

General-purpose mathematical construction-to-code plugin. Converts explicit constructions in mathematical papers, Writee drafts and Researchee handoffs into executable **mathematically annotated** code. Default output: code, run commands, concise actual results. Verification checks both implementation fidelity and whether coded mathematical objects satisfy claimed properties. Detailed certificates/reports only on explicit request; exact execution capabilities depend on available local tools and licenses.

Installation: private ChatGPT skills plugin, existing plugin identity retained. Original reference schemas and examples remain for optional advanced certification.
